# IMPORTANT

Upload these FOUR files directly to the ROOT of the GitHub repository:

- index.html
- style.css
- app.js
- firebase.js

Do NOT put app.js/firebase.js inside a js folder for this fixed package.

Then:
1. GitHub repository → Settings → Pages
2. Deploy from branch → main → /(root)
3. Save
4. Wait about 1–2 minutes
5. Open the Pages URL and press Ctrl+F5

Expected message:
Firebase connected successfully!

Then verify:
Firebase Console → Authentication → Users
A new anonymous user should appear.

If it fails, the page itself will now show the Firebase error code/message.
