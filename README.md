# Nutrition Ludo - Firebase Connection Test

Upload the CONTENTS of this project to the root of your GitHub repository.

Files:
- index.html
- style.css
- js/firebase.js
- js/app.js

Then enable GitHub Pages:
Settings → Pages → Deploy from a branch → main → /root

Open the GitHub Pages URL.
If you see "Firebase connected successfully!", the connection works.

Also check:
Firebase Console → Authentication → Users
A new anonymous user should appear.
